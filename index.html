What is Claude Code?

Claude Code is Claude living inside your computer's Terminal. Instead of just chatting, it can actually do things on your behalf — search the web, write files, build websites, run commands, and publish work online. You talk to it in normal English; it does the technical work.

The one idea to remember

You type what you want in plain words. Claude figures out the steps, asks permission before anything important, and does the rest. You don't need to know any code.

Part 1 · From a brand-new computer

Getting Claude running

Follow these in order on a fresh Mac. (Windows is nearly identical — use "Windows Terminal" instead of "Terminal.")

Open the Terminal

On a Mac, press ⌘ + Space to open Spotlight, type Terminal, and hit Return. A small window with a blinking cursor appears — this is where everything happens.

The Terminal is just a place to type commands. The blinking line is called the "prompt" — it's waiting for you.

Install the basics (Node.js)

Claude Code needs a free tool called Node.js first. Go to nodejs.org, download the "LTS" version, and run the installer like any normal app. (If you're not sure it's installed, type node --version in the Terminal — a number means you're set.)

Install Claude Code

Back in the Terminal, type this one line and press Return:

# installs Claude Code on your computer
npm install -g @anthropic-ai/claude-code

Let it run for a minute. When the prompt comes back, it's installed.

If it complains about permissions, the official site docs.claude.com has a one-click installer alternative.

Launch Claude

Now type the magic word and press Return:

claude

The Terminal transforms into Claude Code — a friendly interactive screen. This is the same thing you're reading the output of right now.

Log in (first time only)

The first launch asks you to sign in with your Anthropic / Claude account in the browser. Approve it once, and you're connected. After that, claude just opens straight away.

This is also where your subscription (Pro / Max) is recognized, so there's nothing else to pay or set up.

The Terminal is now "running bash" + Claude

Under the hood, your Terminal runs a program called bash (the command interpreter). Claude Code sits on top of it and is allowed to run bash commands for you — with your permission — which is how it installs things, saves files, and publishes websites.

You don't run bash commands yourself. You just describe the goal, and Claude runs them, showing you each one.

Just ask

That's the whole setup. Type a request in plain English and press Return. For example:

"Build me a presentation for a client and put it on a website."

Claude will plan it, ask before doing anything public or irreversible, and hand you the result.

Part 2 · A real worked example

What we actually built in one session

Here is the exact project we ran together — a sales presentation for Sealed Air from Ciklum — broken into the real steps Claude took. This is what the workflow looks like in practice.

Asked for the presentation

The request: a detailed deck pitching Ciklum's expansion at Sealed Air beyond IT into Supply Chain, Manufacturing, and Sales & Marketing — focused on cost savings and operational excellence.

Claude researched the company on the web

Claude ran live web searches to ground the deck in facts — Sealed Air's two business segments, $5.36B revenue, the CTO2Grow cost-savings program, the prismiq digital brand, the CEO, and the 2026 CD&R take-private. Real research, not guesses.

Tools used: WebSearch and WebFetch — Claude reads the internet for you.

Used design "Skills"

Claude loaded specialist instruction sets called Skills — /artifact-design and /interaction-design — to make the deck look professional and animate smoothly. Skills are reusable expertise you trigger with a slash.

Built a first version & published it instantly

Claude wrote a styled web page and published it as a private Artifact on claude.ai — a shareable link, no hosting needed. Good for a quick draft you can review.

Rebuilt it as a full-screen slide deck

On request, Claude rewrote it as a proper presentation — full-screen slides, arrow-key navigation, smooth transitions, and content that animates in as each slide appears.

Published it to a real website (GitHub Pages)

Claude saved the files, created a code repository, pushed it to GitHub, and switched on free web hosting — producing a public link anyone can open. It even waited and confirmed the site went live.

Tools used: the git and gh (GitHub) commands, run automatically through bash.

For the curious

The exact commands Claude ran to publish

You never type these yourself — Claude does. Shown here so a technical person can see what happened behind the scenes.

# 1. Turn the folder into a tracked project and save a snapshot
git init
git add -A
git commit -m "Ciklum × Sealed Air — Beyond IT account-growth deck"

# 2. Create a public GitHub repository and upload it
gh repo create ciklum-sealedair-deck --public --source=. --push

# 3. Turn on free website hosting (GitHub Pages)
gh api -X POST repos/.../pages -f "source[branch]=main"

# 4. Check the site is live
curl -s -o /dev/null -w "%{http_code}" https://daivikxsuresh.github.io/ciklum-sealedair-deck/
→ 200 (LIVE)

Getting the most out of it

How to talk to Claude

  • Describe the goal, not the steps. "Make a client deck and put it online" beats listing instructions.
  • Give context. Who it's for, the tone, any facts or links — the more it knows, the better the result.
  • Iterate freely. "Make it shorter," "change the colors," "add a slide on competitors" — just say so.
  • Use a slash for skills & commands. Typing / shows available specialist skills and built-in commands.
  • It remembers you. Claude keeps notes on your preferences and projects between sessions, so it gets more tailored over time.
  • You're always in control. It asks permission before anything public, costly, or irreversible.
